# 4.1 Artificial Intelligence Technique Used

## Random Forest Classifier

The proposed wearable health monitoring system uses the **Random Forest Machine Learning Algorithm** for real-time health condition prediction.

Random Forest is an ensemble learning technique that combines multiple Decision Trees to improve prediction accuracy and reduce overfitting. Each tree independently evaluates the input features and predicts a class label. The final output is determined using majority voting among all trees.

### Basic Structure

```text
Input Features
       │
       ▼
 Multiple Decision Trees
       │
       ▼
 Majority Voting
       │
       ▼
 Final Prediction
```

### Advantages of Random Forest

* High prediction accuracy
* Fast execution on ESP32-S3
* Suitable for TinyML deployment
* Handles noisy physiological data effectively
* Low computational complexity
* Supports real-time Edge AI inference

# 4.3 Feature Description

## RR Interval

RR Interval is the time difference between two consecutive R-peaks in an ECG signal. It represents the cardiac rhythm and is widely used for calculating heart rate and rhythm regularity. Irregular RR intervals may indicate arrhythmias or abnormal cardiac activity.

---

## Peak Amplitude

Peak amplitude is the maximum ECG voltage observed during a heartbeat. It reflects the strength of the heart's electrical activity and helps identify abnormal waveform patterns.

---

## Beat Standard Deviation

Beat standard deviation measures the variability of ECG samples within a heartbeat. Larger deviations often indicate irregular waveform morphology and abnormal cardiac behaviour.

---

## Beat Energy

Beat energy represents the total power contained within an ECG beat. It is calculated from squared ECG amplitudes and helps characterize waveform intensity and structure.

---

## Heart Rate (HR)

Heart Rate indicates the number of heart beats per minute (BPM). Increased heart rate is commonly associated with stress, exercise, or cardiac abnormalities, while reduced heart rate may indicate bradycardia.

---

## Heart Rate Variability (HRV)

HRV measures the variation between consecutive heart beats. Higher HRV generally indicates healthy autonomic regulation, whereas lower HRV is frequently associated with stress and fatigue.

---

## Body Temperature

Body temperature is measured using the MLX90614 infrared sensor. Physiological stress and certain medical conditions can produce slight variations in body temperature.

---

## Motion Level

Motion level is derived from MPU6050 accelerometer data. It indicates physical activity intensity and helps distinguish exercise-related physiological changes from stress-related changes.

# 4.4 ECG Classification Model

## Model Overview

The ECG Classification Model analyzes ECG-derived features and predicts cardiac condition classes.

### Model Type

Random Forest Classifier

### Purpose

Detection of ECG abnormalities and cardiac irregularities.

### Model Structure

| Property        | Value           |
| --------------- | --------------- |
| Algorithm       | Random Forest   |
| Number of Trees | 22              |
| Input Features  | 4               |
| Output Classes  | 6               |
| Decision Method | Majority Voting |

### Input Features

1. RR Interval
2. Peak Amplitude
3. Beat Standard Deviation
4. Beat Energy

### Input Format

```cpp
[
 rr_interval,
 peak_amp,
 beat_std,
 beat_energy
]
```

### Function Definition

```cpp
int ecg_predict(
    float rr_interval,
    float peak_amp,
    float beat_std,
    float beat_energy
);
```

### Output Format

```cpp
int ecg_class;
```

### Output Range

```text
0 – 5
```

# 4.6 Fusion Model

## Model Overview

The Fusion Model combines predictions from both the ECG Model and Stress Model to generate a final health assessment.

### Model Type

Rule-Based Decision Fusion

### Purpose

Integration of cardiac health information and stress information.

### Input Parameters

1. ECG Classification Result
2. Stress Classification Result

### Input Format

```cpp
[
 ecg_class,
 stress_class
]
```

### Function Definition

```cpp
int fusion_predict(
    int ecg_class,
    int stress_class
);
```

### Output Format

```cpp
int final_status;
```

### Output Labels

| Output        | Meaning                             |
| ------------- | ----------------------------------- |
| HEALTHY       | Normal ECG and Normal Stress        |
| STRESSED      | Stress Detected                     |
| CARDIAC_ALERT | ECG Abnormality Detected            |
| HIGH_RISK     | ECG Abnormality and Stress Detected |

# 4.7 AI Inference Workflow

## Step 1: Data Acquisition

Sensors continuously collect:

* ECG Signal
* Heart Rate
* SpO₂
* Body Temperature
* Motion Data

---

## Step 2: Feature Extraction

ESP32-S3 processes the signals and extracts:

* RR Interval
* Peak Amplitude
* Beat Standard Deviation
* Beat Energy
* Heart Rate
* HRV
* Temperature
* Motion Level

---

## Step 3: ECG Classification

Extracted ECG features are processed by the ECG Random Forest model.

```text
ECG Features
      │
      ▼
ECG Random Forest
      │
      ▼
ECG Class
```

---

## Step 4: Stress Classification

Stress-related physiological features are processed by the Stress Random Forest model.

```text
Stress Features
       │
       ▼
Stress Random Forest
       │
       ▼
Stress Class
```

---

## Step 5: Fusion Decision

Outputs from both models are combined by the Fusion Model.

```text
ECG Class
      +
Stress Class
      │
      ▼
Fusion Model
      │
      ▼
Final Health Status
```

---

# 4.8 Final AI Outputs

The system can identify:

# 4.9 Final Objective

The final objective of the proposed system is to develop a wearable Edge AI health monitoring platform capable of continuously analyzing ECG, Heart Rate, SpO₂, Temperature and Motion signals to detect stress, ECG abnormalities and cardiac risk conditions in real time without requiring cloud-based processing.
